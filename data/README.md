# Data Directory Structure

This directory contains raw and processed data for the FitLife Wellness Intelligence application.

- `raw/`: Stores the original Fitabase smart-device dataset. This folder is ignored by git to keep the repository lightweight and follow data privacy practices.
- `processed/`: Stores cleaned, aggregated, and integrated datasets (e.g., `daily_master.csv`, `hourly_master.csv`, `heart_rate_daily.csv`) generated by the ETL pipeline.
